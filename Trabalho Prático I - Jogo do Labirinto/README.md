# Aventura no Labirinto

Um jogo imersivo para o terminal construído em Python. Navegue pelo labirinto, colete pontos, desvie de paredes e alcance a saída!

## Funcionalidades
- **Interface visual formatada:** Uso do pacote `rich` para exibição aprimorada de componentes no terminal.
- **Movimentação ao vivo:** Uso da biblioteca `pynput` permitindo controle nas teclas `W, A, S, D` sem exigir a tecla `Enter`.
- **Recursividade em destaque:**
  - Desafio Extra: Resolução algorítmica recursiva visualizada (Backtracking).
  - Celebração animada para o término de uma partida vitoriosa.
- **CLI customizável:** Alteração de parâmetros como cor, nome de usuário e tamanho dos mapas diretamente pela chamada do comando.
